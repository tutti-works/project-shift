## **📄 プロジェクト要件定義書**

### **1\. プロジェクト概要**

* **プロジェクト名:** 縁バース芸術祭 展示作品「SHIFT」インタラクティブWebコンテンツ  
* **目的:** 浅川竜成氏の修士制作「SHIFT」のコンセプトを、Web上でインタラクティブに体験できる3Dコンテンツとして展示・紹介する。

* **閲覧環境:** PCおよびスマートフォンのWebブラウザ（レスポンシブ対応）

### **2\. 機能要件**

* **3Dシーンの表示:**  
  * メインの構造体（羽板・リボン・ワイヤーのユニット）を3D空間に表示する。  
  * ライティングとシャドウを適切に設定し、構造体の形状や動き、素材感（木材、布、金属）が立体的に認識できるようにする。  
* **スクロール連動アニメーション:**  
  * Webページのスクロール操作（上下）に連動して、3Dシーン内のアニメーション（ユニットの変形、カメラワーク）がシームレスに進行する。  
  * スクロールは可逆的（上に戻ればアニメーションも逆再生される）であること。

### **3\. 非機能要件**

* **使用技術:** React (Next.js推奨)、React Three Fiber (R3F)、drei、Three.js
* **パフォーマンス:** 51本の複雑な変形を行うユニットを効率的に描画するため、**InstancedMesh** および **カスタムシェーダー (GLSL)** の使用を必須とする。
  * **目標:** PC環境で60fps、スマートフォン環境で30fps
  * 初期実装ではプロトタイプ（1本のユニット）で検証し、パフォーマンスは段階的に最適化する
* **メンテナンス性（調整可能性）:**
  * アニメーションの各種パラメータ（例：リボンの最大/最小ねじれ角度、サイン波の速度・振幅）は、コード内の単一のコンフィグファイルまたは変数として定義し、実装完了後も容易に微調整できるようにする。
* **ブラウザ対応:** 技術的に可能な範囲で最大限のブラウザに対応する（WebGL 2.0サポートを基準とする）

### **4\. 仕様詳細：3Dモデル**

* **構成ユニット:** 1ユニットは「羽板」「リボン」「ワイヤー」の3要素で構成される。
* **ユニット総数:** **51本**
* **配置:**
  * X軸方向に直線状に等間隔で配置
  * 26本目（中央のユニット）が原点（X=0）に位置するように配置
  * 1本目から51本目まで、X軸負方向から正方向へ並ぶ
* **寸法:**
  * **羽板:** 幅 100mm、厚さ 4mm、高さ 3762mm
  * **リボン:** 幅 100mm、厚さ 2mm（平たい形状）
  * **ワイヤー:** 直径 2mm（円柱状）
  * **ユニット間隔:** 各羽板の隙間は 20mm（羽板幅100mm + 隙間20mm = ピッチ120mm）
  * **アンカー位置:** 羽板の中心（地面）から、リボンおよびワイヤーのアンカーポイント（地面）までの水平距離は、それぞれ 2400mm
* **マテリアル:**
  * **羽板:** 木材色（#e5bb72）、木材質感
  * **リボン:** 白色（#ffffff）、半透明な布質感
  * **ワイヤー:** グレー（#888888）、金属質感

### **5\. 仕様詳細：アニメーション（スクロール連動）**

#### **5.1. 全体シーケンス**

Webページのスクロール位置（0%〜100%）に応じて、以下のアニメーションを連動させる。

| スクロール位置 | 羽板の変形（しなり） | リボンの変形（ねじれ） | カメラワーク |
| :---- | :---- | :---- | :---- |
| **0%** (初期状態) | 全ユニット：**垂直（しなり 0）** | 全ユニット：**ねじれ 0** | **位置A**（正面斜め上から俯瞰） |
| **0% → 50%** (変形) | **中央**（26本目）からしなり開始。 サイン波で左右（1本目, 51本目）へ伝播。 最終的に全ユニットが\*\*最大（4分の1円弧）になる。 | 羽板のしなりに連動し、ねじれが発生。 しなり最大時にねじれも最大になる。 | 位置A → 位置B（背面斜め上）へ、構造体を回り込むようにオービット移動。 |
| 50% → 100% (復帰) | B側（仮：51本目側）から復帰開始。 サイン波でA側（仮：1本目側）へ伝播。 最終的に全ユニットが垂直\*\*に戻る。 | 羽板の復帰に連動し、ねじれも0に戻る。 | 位置B → **位置A**（初期位置）へ、オービット移動して戻る。 |

#### **5.2. 羽板の「しなり」表現**

* **要件:** 板が軸回転するのではなく、物理的に「しなる」（湾曲する）こと。状態0（直線）から状態1（4分の1円弧）までを滑らかに変形させる。  
* **実装方針:**  
  1. 羽板のジオメトリ（PlaneGeometryまたはBoxGeometry）を作成。  
  2. InstancedMesh を使用して51本配置。  
  3. **カスタムシェーダー (Vertex Shader)** を作成。  
  4. useFrame フック（毎フレーム実行）内で、スクロール位置とサイン波の計算式に基づき、各インスタンス（各羽板）の「しなり具合（0.0〜1.0）」を計算する。  
  5. 計算結果を InstancedMesh 経由でシェーダーに転送。  
  6. シェーダー側で、受け取った「しなり具合」の値に基づき、頂点の position を計算し直し、直線と円弧の間を補間するように頂点を動かす。（例：ベジェ曲線や sin を用いた計算）

#### **5.3. リボンの「ねじれ」表現**

* **要件:** 平たいリボンが、根本（地面側）で最もねじれ、先端（羽板側）ではねじれない、グラデーション状のねじれを表現する。  
* **実装方針:**  
  1. リボンのジオメトリ（PlaneGeometry）を作成。  
  2. InstancedMesh を使用して51本配置。  
  3. **カスタムシェーダー (Vertex Shader)** を作成（羽板とは別）。  
  4. シェーダー側で、頂点のY座標（高さ）を取得。  
  5. Y座標（0.0〜1.0）に基づき、ねじれ角度を計算（twistAngle \= maxAngle \* (1.0 \- y)）。  
  6. この角度に基づき、頂点をY軸中心に回転させ、ねじれを表現する。  
  7. 「しなり具合」に応じて maxAngle（調整可能なパラメータ）を 0 から最大値まで変動させる。

#### **5.4. ワイヤーの「挙動」表現**

* **要件:** ワイヤーは常に伸縮し、地面のアンカーポイントと羽板の先端を結ぶ。板が湾曲した際は、円弧の接線となるように形状を維持する。
* **実装方針:**
  1. ワイヤーのジオメトリ（CylinderGeometry または TubeGeometry）を作成。
  2. InstancedMesh を使用して51本配置。
  3. useFrame フック内で、しなり計算によって算出された「羽板の先端座標」を取得。
  4. **ロジックA（単純実装・優先）:** 地面アンカーと羽板先端の2点を結ぶように、各インスタンスの「位置」「回転」「スケール（長さ）」をリアルタイムで更新する。
  5. **ロジックB（高度実装・余裕があれば検討）:** ロジックAの直線が羽板の円弧と交差する場合、直線部分と円弧の接線部分を組み合わせた形状を TubeGeometry などで動的に生成する。

#### **5.5. カメラワーク**

* **カメラターゲット:** 構造体全体の中心（26本目のユニット中心、高さは構造体の半分の高さ）
* **カメラ軌道:** 円弧状にオービット移動（構造体を中心に回り込むように移動）
* **カメラ位置:**
  * **位置A（初期位置・0%/100%）:** 正面斜め上から俯瞰する位置
    * 方位角: 45度（正面やや右側）
    * 仰角: 30度（斜め上から）
    * 距離: 構造体全体が収まる距離（約8000mm程度）
  * **位置B（中間位置・50%）:** 背面斜め上から俯瞰する位置
    * 方位角: 225度（背面やや左側）
    * 仰角: 30度（斜め上から）
    * 距離: 位置Aと同じ
* **カメラ移動:**
  * 0%→50%: 位置A → 位置B へ円弧状にスムーズに移動
  * 50%→100%: 位置B → 位置A へ円弧状に戻る

1. **Phase 1: プロトタイプ（1本のユニット）** ✅ **完了**
   * 1本の羽板・リボン・ワイヤーのセットで、しなり・ねじれ・接続のアニメーションを実装 ✅
   * カスタムシェーダーの動作検証 ✅
   * パフォーマンス計測と実現可能性の確認 ✅
   * **達成事項:**
     * 羽板の円弧状のしなりアニメーションをカスタムシェーダーで実装
     * **羽板の陰影実装**（Jacobian逆転置行列による法線再計算 + Blinn-Phongライティング）
     * リボンの根本から先端へのグラデーション状ねじれアニメーションを実装
     * ワイヤーの動的な2点間接続（地面アンカー ⇔ 羽板先端）を実装
     * 曲面シャドウ対応（カスタムDepth/DistanceMaterialによるシャドウシェーダー統合）
     * デバッグGUI実装（lil-gui）によるリアルタイムパラメータ調整機能
     * **デバッグヘルパー実装**（法線可視化・座標軸・シャドウカメラ）
     * **コンポーネント分離**（BladeDebugSceneディレクトリ化）
     * スクロール連動アニメーション（0%→50%→100%）の動作確認
   * **調整可能なパラメータ（デバッグGUI）:**
     * Wire Thickness: ワイヤーの太さ（0.5〜20mm）
     * Blade Thickness: 羽板の厚さ（1〜60mm）
     * Ribbon Twist (deg, rest): リボンの静止時ねじれ角度（-180〜180度）
     * Ribbon Twist (deg, max): リボンの最大曲げ時ねじれ角度（-180〜360度）
     * Ambient Intensity: 環境光強度（0〜1.5）
     * Specular Intensity: 鏡面反射強度（0〜1）
     * Specular Power: 鏡面反射鋭さ（1〜256）
     * Directional Intensity: 平行光源強度（0〜5）
     * Show Normals: 法線可視化トグル
     * Show Axes: 座標軸表示トグル
     * Show Shadow Helper: シャドウカメラ可視化トグル
